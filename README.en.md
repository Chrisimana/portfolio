## 📋 About

This portfolio showcases the development and design projects I have worked on over time. It is a fully static site built with Nuxt and Vue: every page is prerendered to HTML at build time, available in Indonesian and English, and deployed as static files to Cloudflare Pages. Guiding principles: no database, no admin panel, no runtime API, and no dependency that requires an account or API key. All content comes from files, and invalid content fails the build.

## 🛠️ Built With

- **Nuxt 4** + **Vue 3** (Composition API) + **TypeScript** (`strict`)
- **Tailwind CSS 4** : a hand-built design system
- **Nuxt Content** : Markdown + frontmatter as the single source of data
- **@nuxtjs/i18n** : bilingual ID/EN with `hreflang` & `canonical`
- **@nuxt/image** : responsive images generated at build time
- **Vitest** + **Playwright** + **axe-core** : unit, component, E2E, and accessibility
- **Cloudflare Pages** : static hosting

---

## ✨ Highlights

- Full prerender, every page becomes static HTML, no runtime server
- Theme follows the system preference (dark/light), with a manual override
- Category filter & search that appear automatically based on the content
- Complete SEO: Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`
- Accessibility tested automatically; Lighthouse desktop 100/100/100/100
