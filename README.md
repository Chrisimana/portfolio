## 📋 Tentang

Portofolio ini menampilkan proyek pengembangan dan desain yang telah saya kerjakan selama ini. Dibangun sebagai situs statis penuh dengan Nuxt dan Vue, setiap halaman diprerender menjadi HTML saat build, tersedia dalam Bahasa Indonesia dan Inggris, dan di-deploy sebagai berkas statis ke Cloudflare Pages. Prinsip yang dipegang, tanpa database, tanpa admin panel, tanpa API runtime, tanpa dependency yang butuh akun atau API key. Seluruh konten berasal dari berkas, dan konten yang tidak valid menggagalkan build.

## 🛠️ Dibangun Dengan

- **Nuxt 4** + **Vue 3** (Composition API) + **TypeScript** (`strict`)
- **Tailwind CSS 4** : design system dibangun sendiri
- **Nuxt Content** : Markdown + frontmatter sebagai sumber data tunggal
- **@nuxtjs/i18n** : dwibahasa ID/EN dengan `hreflang` & `canonical`
- **@nuxt/image** : gambar responsif dihasilkan saat build
- **Vitest** + **Playwright** + **axe-core** : unit, komponen, E2E, dan aksesibilitas
- **Cloudflare Pages** : hosting statik

---

## ✨ Sorotan

- Prerender penuh, setiap halaman menjadi HTML statis, tanpa server runtime
- Tema mengikuti preferensi sistem (gelap/terang), dengan opsi override manual
- Filter kategori & pencarian yang muncul otomatis mengikuti isi konten
- SEO lengkap: Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`
- Aksesibilitas diuji otomatis. Lighthouse desktop 100/100/100/100
